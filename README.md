# Agentic SIEM – Autonomous Cyber-Threat Hunting

## Project Overview
An academic Data Mining project focused on detecting and responding to cyber threats using a multi-agent architecture.

## Dataset
- UNSW-NB15 (planned initial dataset)
- CICIDS2017 (alternative)

## Machine Learning Techniques
- Naive Bayes
- Logistic Regression
- Recurrent Neural Network (RNN)
- Decision Tree

## Proposed Architecture
1. Detection Agent
2. Behaviour Analysis Agent
3. Response and Mitigation Agent
4. Central Agent Coordinator
5. Monitoring Dashboard

## Technologies
- Python
- pandas
- NumPy
- scikit-learn
- PyTorch
- Streamlit
